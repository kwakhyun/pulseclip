# PulseClip 제품 기획서

## 제품 정의

PulseClip은 Windows 10/11 사용자가 게임 플레이를 끊김 없이 녹화하고, 놓친 순간을 전역 단축키 한 번으로 최근 구간부터 저장할 수 있는 로컬 우선 무료 데스크톱 앱이다. 계정, 구독, 광고, 클라우드 업로드 없이 핵심 녹화 경험을 제공한다.

## 해결할 문제

- 게임 도중 녹화를 켜지 않아 결정적인 장면을 놓친다.
- 기존 방송 도구는 설정 항목이 많고 클립 관리가 번거롭다.
- 장시간 녹화는 메모리와 저장공간을 과도하게 사용한다.
- 시스템 소리와 마이크를 함께 담는 과정이 어렵다.
- 무료 도구 중에는 개인정보 처리와 저장공간 정책이 불명확한 경우가 많다.

## 핵심 사용자 흐름

1. 첫 실행에서 화면 또는 게임 창, 품질, 오디오를 선택한다.
2. `리플레이 준비`를 켜면 인코딩된 최근 구간만 메모리에 순환 보관한다.
3. 게임 중 `F8`로 최근 45초를 저장하거나 `F9`로 일반 녹화를 시작/종료한다.
4. 라이브러리에서 즉시 재생, 즐겨찾기, 파일 위치 열기, 삭제를 수행한다.
5. 저장 한도에 도달하면 즐겨찾기하지 않은 오래된 클립부터 안전하게 정리한다.

## v1 범위

- 화면/창 소스 선택과 미리보기
- 720p/1080p/1440p/원본, 30/60 FPS, 4~40 Mbps
- H.264 하드웨어 우선 인코딩과 VP9·VP8 영상 폴백, AAC 우선·Opus 오디오 폴백
- Windows 시스템 오디오 루프백, 선택적 마이크 믹싱
- 최근 15~180초 즉시 리플레이
- 장시간 수동 녹화의 스트리밍 디스크 기록
- 전역 단축키, 시스템 트레이, 시작 프로그램
- 로컬 클립 라이브러리, 즐겨찾기, 검색, 저장공간 한도
- 중단된 fragmented MP4 복구, 원자적 설정 저장, 구조화 로그
- x64/arm64 NSIS 설치 패키지

## 의도적으로 제외한 범위

- 서버 비용과 운영 체계가 필요한 계정, 클라우드 동기화, 소셜 피드
- 모델 학습/추론 인프라가 필요한 AI 하이라이트 자동 편집
- 게임 메모리 읽기, 안티치트 후킹, DLL 인젝션
- DRM 또는 보호된 영상 캡처 우회

## 품질 목표

- 캡처 준비: 일반 PC에서 3초 이내
- 리플레이 저장: 45초 1080p 클립을 5초 이내 컨테이너화
- 메모리: 리플레이 설정 길이에 비례하는 인코딩 패킷만 보관
- 장시간 녹화: 전체 영상을 RAM에 적재하지 않고 디스크로 스트리밍
- 데이터: 네트워크 전송 0, 삭제 전 명시적 사용자 동작 또는 저장 한도 정책 필요
- 복구: 비정상 종료 후 최소 한 개의 완전한 미디어 조각이 확인된 fragmented MP4를 다음 실행에서 복구하고, 구조가 불완전한 `.part`는 원본 상태로 보존

## 2단계 확장

- 게임 프로세스 감지 및 게임별 프로필
- Direct3D 네이티브 캡처 엔진 선택지와 NVENC/AMF/QSV 세부 제어
- 로컬 장면 감지/킬 이벤트 플러그인
- 비파괴 트림, 세로형 숏폼 내보내기, 오버레이 편집
- 선택적 종단간 암호화 클라우드 백업

## 출시 게이트

- Windows 10 22H2, Windows 11 최신 두 버전에서 30/60 FPS 검증
- Intel/NVIDIA/AMD GPU 각 1종 이상에서 30분 녹화와 50회 리플레이 반복
- 시스템 오디오만, 마이크만, 혼합 오디오 조합 검증
- 멀티 모니터, 창 크기 변경, 화면 절전, 소스 종료 복구 검증
- 코드 서명, 설치/업데이트/제거, SmartScreen 평판 계획 완료
- 개인정보 처리방침과 오픈소스 고지 포함

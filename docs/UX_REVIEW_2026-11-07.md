# 기능·UI/UX 검토와 개선 결과 · 2026-11-07

기준: `v0.1.4` 소스. 이 문서의 개선은 공개 릴리스 전 개발 브랜치에 반영했으며, 다음 릴리스 노트에 옮겨야 한다.

## 검토 기준

PulseClip의 핵심 약속은 "리플레이를 켜 두면 게임 중 F8 한 번으로 지나간 장면을 저장한다"이다. 이 약속을 깨는 경로를 P0, 저장 이후의 정리·편집·공유 불편을 P1, 디자인 시스템 부채를 P2로 분류했다.

## P0 — 핵심 약속을 깨는 문제

| 문제 | 원인 | 조치 |
| --- | --- | --- |
| 앱을 다시 켜면 리플레이가 꺼져 있어 F8이 아무것도 저장하지 못함 | `autoStartBuffer` 기본값 꺼짐, 온보딩에서 묻지 않음, 트레이에는 "끄기"만 있음 | 새 설치 기본값을 켬으로 변경, 온보딩 4단계에서 자동 시작·Windows 시작 시 실행 선택, 트레이에 켜기/끄기 토글 |

## P1 — 사용성

- **홈 위계:** "리플레이 준비"를 주 패널로 올리고 버퍼 게이지(최근 N초/설정 길이)를 표시했다. 전체 녹화는 보조 버튼으로 내렸다. 2026-08 UI 감사(`artifacts/ui-audit`)는 `전체 녹화 시작`을 주 CTA로 정했지만, 제품 문구와 랜딩의 핵심 흐름이 리플레이이므로 위계를 다시 맞췄다. 중복된 원형 녹화 버튼과 상태 표시를 제거했다.
- **입력 확인:** 게임 소리·마이크의 실시간 입력 레벨 미터를 추가했다. 단축키 등록 실패를 홈 카드에서 경고하고 설정으로 연결한다.
- **클립 관리:** 직접 삭제는 Windows 휴지통으로 이동하고, 자동 정리는 정리한 개수와 확보 용량을 알린다. 썸네일은 검은 첫 프레임 대신 클립 앞부분의 장면을 표시하고, 홈의 최근 클립도 같은 썸네일을 쓴다.
- **공유:** 클립 카드와 플레이어의 "끌어서 공유"로 실제 MP4를 Discord·탐색기·편집 프로그램에 끌어다 놓을 수 있다.
- **구간 편집:** 두 개의 독립 슬라이더를 선택 구간·재생 위치가 보이는 하나의 타임라인으로 바꿨다. `I`/`O`로 시작·종료를 지정하고 `Space`로 재생한다. 편집 중에는 영상 높이를 줄여 하단 버튼이 잘리지 않게 했다.
- **설정·정보:** 섹션 이동 버튼, "정보" 섹션의 업데이트 확인, 실제 동작에 맞춘 알림 설명, "현재 프로필" → "현재 구성".
- **창·트레이:** 최대화/복원 아이콘 전환, 상태별 트레이 아이콘 점, 메뉴를 매초 다시 만들지 않음.
- **토스트:** 사이드바 저장공간 카드를 가리지 않도록 오른쪽 아래로 옮기고, 오류는 닫을 때까지 유지한다.

## P2 — 디자인 시스템

- 기본 스타일의 7~9px 글자 중 덮어쓰지 않고 남은 클립 종류 배지·길이·통계 단위 등을 11~12px로 올렸다.
- 영어 장식 문구(GAME CAPTURE STUDIO 등)를 화면 역할을 설명하는 한국어로 바꿨다.
- 남은 과제: `foundation → accessibility → workbench → experience`로 쌓인 덮어쓰기 계층과 273개의 하드코딩 색상을 공통 토큰으로 통합해야 한다.

## 남은 과제

- 클립 파일을 클립보드에 복사(CF_HDROP)는 Electron 기본 API로 지원되지 않아 끌어다 놓기로 대체했다.
- 게임 이름 자동 태그(저장 시점의 전면 창), 여러 클립 일괄 선택, 날짜별 묶음, Discord 용량 맞춤 내보내기.
- 효과음은 시스템 오디오 녹음에 함께 담길 수 있다. 근본 해결은 로드맵의 클릭 통과 오버레이다.
- 잠금 해제 후에는 리플레이만 다시 켠다. 잠금 전 진행 중이던 전체 녹화는 저장 후 종료되며 자동으로 이어 녹화하지 않는다.

## 검증

- `npm run verify`: 타입 검사, 단위 테스트 79개, 프로덕션 빌드 통과.
- `npm run test:desktop`(기본·`--mono-audio`): 실제 Electron에서 장치 복구, 버퍼 게이지·레벨 미터, 녹화 중 리플레이, 이름 변경, 구간 편집·취소, 최소 창 레이아웃, 설정 저장, 단축키 검증(중복·단일 문자), 리플레이가 꺼진 상태의 F8, 잠금 해제 후 재개, 대기열에 넣은 단축키 실행을 확인했다.
- 위 통합 검사는 Linux Xvfb(`--disable-gpu`)에서 실행했다. Windows 전용 동작(휴지통 이동, 트레이 아이콘, 전역 단축키 일시 해제, 끌어다 놓기, 실제 절전·잠금 이벤트)은 Windows 실기기에서 확인해야 한다.
- 개선 화면은 [artifacts/ux-review-2026-11-07](../artifacts/ux-review-2026-11-07/)에 있다. Linux에서 캡처해 Windows와 글꼴이 다르다.

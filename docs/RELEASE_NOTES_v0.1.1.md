# PulseClip v0.1.1 — Reliability Update

`v0.1.1`은 녹화 데이터 보존과 공개 배포 안전성을 강화한 패치 릴리스입니다.

## 주요 변경

- 앱 종료 시 렌더러가 진행 중인 녹화를 마무리할 때까지 기다리는 정상 종료 핸드셰이크 추가
- 렌더러 비정상 종료 시 열린 쓰기 세션을 닫고 복구 가능한 fragmented MP4를 보존한 뒤 화면을 자동 재로드
- 반복 렌더러 충돌을 감지해 무한 재시작 대신 녹화 파일 보존 후 안전 종료
- 손상된 설정 파일 원본 백업, 설정 저장 실패 시 메모리 상태 롤백, 잘못된 클립 ID의 안정적인 UUID 복구
- MP4 박스 구조를 확인한 `.part` 파일만 라이브러리에 등록하고 불완전한 파일은 원본 상태로 보존
- 로그 순환과 순환 참조·중첩 오류 직렬화 보강
- “닫을 때 트레이로 최소화”를 끈 경우 창만 사라지는 문제를 수정하고 정상 종료 경로로 연결
- 데스크톱·랜딩 CSP 강화, 개인정보 처리방침 추가, Dependabot·시크릿 스캐닝·푸시 보호 활성화
- Windows 패키징을 CI 필수 검증 단계로 추가

## 검증

- 데스크톱 타입 검사, 25개 단위 테스트, 프로덕션 빌드, x64 Windows 패키징
- 랜딩 SSR·프리렌더 빌드, 7개 호스팅 번들 테스트
- 데스크톱과 랜딩 프로덕션 의존성 감사: 알려진 취약점 0건

## 설치 파일

- `PulseClip-0.1.1-Setup.exe`: x64·Arm64 통합 설치 파일
- `PulseClip-0.1.1-x64-Setup.exe`: 일반 Intel/AMD Windows PC
- `PulseClip-0.1.1-arm64-Setup.exe`: Windows on Arm PC

이번 공개 베타는 아직 Authenticode로 서명되지 않았습니다. Windows SmartScreen 경고가 나타날 수 있으므로 함께 제공되는 `SHA256SUMS.txt`로 무결성을 확인해 주세요. 자동 업데이트는 신뢰된 코드 서명과 HTTPS 업데이트 피드가 준비될 때까지 비활성화되어 있습니다.

# 보안 및 개인정보 원칙

- PulseClip은 기본 설정에서 외부 서버로 네트워크 요청을 보내지 않는다.
- 캡처 영상, 시스템 소리, 마이크 소리는 사용자가 지정한 로컬 폴더에만 저장한다.
- 화면 캡처가 활성화되면 앱 상태와 트레이 메뉴에서 항상 확인할 수 있다.
- 보호된 콘텐츠를 우회하지 않으며 Windows 또는 콘텐츠 제공자가 차단한 프레임은 녹화하지 않는다.
- 임의 경로를 IPC로 받지 않고, 등록된 clip ID 또는 사용자가 디렉터리 선택기로 승인한 폴더만 사용한다.
- 릴리스 전 Electron 보안 업데이트, 의존성 감사, 코드 서명, SBOM 생성이 필요하다.

취약점 신고용 이메일과 공개 보안 정책 URL은 실제 서비스 출시 전에 프로젝트 소유자가 지정해야 한다.
